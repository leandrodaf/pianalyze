# Security Policy

## Supported Versions

Only the latest released version of Pianalyze receives security fixes.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use [GitHub's private vulnerability reporting](https://github.com/leandrodaf/pianalyze/security/advisories/new) for this repository. You should receive an initial response within a few days.

If the report is confirmed, we will work on a fix and coordinate a disclosure timeline with you before publishing details.
